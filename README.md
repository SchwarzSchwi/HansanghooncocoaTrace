# HansanghooncocoaTrace

한국어 Upbit 원화 마켓 실시간 시세 모니터입니다. 외부 라이브러리나 API 키 없이 공개 시세를 화면에 표시합니다.

## 실행

저장소 디렉터리에서 간단한 로컬 서버를 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 열고 검색창으로 종목을 필터링하거나 **다시 연결**을 눌러 WebSocket 연결을 다시 시작할 수 있습니다.

## 데이터 및 설정

- WebSocket URL은 `/app.js`의 `CONFIG.endpoints.tickerWebSocket`에 있습니다.
- 표시할 마켓 코드와 한국어 이름은 같은 파일의 `CONFIG.markets`에 있습니다.
- Upbit의 공개 ticker WebSocket(`wss://api.upbit.com/websocket/v1`)을 사용합니다. 구독은 `format: SIMPLE`, `isOnlyRealtime: false`로 요청하여 연결 시 최신 스냅샷을 받고 이후 실시간 ticker 메시지를 받습니다. 별도의 REST 스냅샷 호출은 하지 않습니다.
- 수신 SIMPLE ticker 응답은 `ty`(`ticker`), `cd`(마켓), `tp`(현재가), `scr`(부호가 있는 전일 대비율), `atp24h`(24시간 누적 거래대금), `c`(전일 대비 방향), `tms`/`ttms`/`timestamp`(밀리초 원천 시각)를 검증한 뒤 표시합니다. 알 수 없는 마켓, 잘못된 값과 현재 시각보다 60초 넘게 앞선 데이터는 거부합니다. 작은 시계 오차 범위 안의 미래 시각, 60초보다 오래된 원천 데이터 또는 연결이 끊긴 동안의 마지막 값은 지연으로 표시하며, 이전 시각의 응답은 이미 표시된 최신 값을 덮어쓰지 않습니다.
- 시작 시 빈 표는 데이터를 기다리는 상태이며, 연결 오류, 데이터 응답 시간 초과, 연결 끊김, 검색 결과 없음은 각각 화면에 표시됩니다. 자동 재연결은 지수형 대기(최대 30초)로 제한됩니다.
- 이 공개 WebSocket을 사용하므로 REST CORS 설정은 적용되지 않습니다. 브라우저와 네트워크가 `wss://api.upbit.com`으로 나가는 연결을 허용해야 합니다. 방화벽, 프록시, 서비스 가용성, 시장 거래 상황에 따라 데이터가 지연되거나 비어 있을 수 있습니다. UI에는 수신한 값만 표시하며 값을 만들어 내지 않습니다.

## 음성 읽기

**화면 내용 읽기**를 직접 눌러 현재 검색 결과의 최대 5개 종목과 원천 시각 및 지연 여부를 읽을 수 있습니다. **읽기 중지**는 현재 발화를 취소합니다. 속도와 사용 가능한 음성을 선택할 수 있으며, 음성 목록이 늦게 제공되는 브라우저에서는 기본 한국어 음성이 선택되고, 음성 합성을 지원하지 않으면 읽기 컨트롤을 사용할 수 없다는 안내가 표시됩니다.

읽기는 페이지 로드, 연결/검색 변경 또는 시세 수신만으로 시작되지 않습니다. 음성은 선택적인 보조 기능이며 청각 접근성을 대체하지 않습니다. 모든 시세와 상태, 오류는 계속 화면에 표시됩니다.

## 검증

Node.js 내장 테스트 러너로 데이터 정규화, 잘못된/빈 응답, stale 처리, 재연결 대기, 음성 미지원/빈 음성 목록과 음성 스냅샷을 검사합니다.

```sh
node --test tests/*.test.cjs
```

수동 브라우저 확인 항목:

1. 페이지를 열고 데이터 대기 후 실제 시세, 검색 결과 없음, 검색 초기화 동작을 확인합니다.
2. 네트워크를 끊어 연결 종료 및 재연결 상태와 마지막 데이터의 `지연` 표시를 확인한 뒤 네트워크를 복원합니다.
3. 키보드만으로 검색, 다시 연결, 음성/속도 선택, 읽기 시작 및 중지를 조작합니다. 페이지 로드와 검색/시세 변경만으로 음성이 시작되지 않는지 확인합니다.
4. 지원 브라우저에서 한국어 음성(있는 경우)과 완료/중지 동작을 확인합니다. 미지원 브라우저에서는 화면 데이터와 상태가 계속 보이는지 확인합니다.

기본 검증은 브라우저 외부에서 실행되는 Node.js 테스트이며 실제 Upbit 연결과 각 브라우저/운영체제 음성은 네트워크 및 음성 엔진이 있는 환경에서 확인해야 합니다.
